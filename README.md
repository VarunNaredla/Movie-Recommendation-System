# Movie Recommendation System

A simple content-based movie recommendation system using Python and Scikit-Learn.

## Features
- Recommends movies based on genres
- Uses cosine similarity
- Easy to extend with larger datasets

## Project Structure

```
movie_recommendation_system/
│── app.py
│── movies.csv
│── requirements.txt
│── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Example:

Input:
```
Inception
```

Output:
```
Interstellar
The Matrix
Avengers: Endgame
Doctor Strange
The Dark Knight
```
